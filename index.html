Clé API Groq

Nécessaire pour la transcription et le résumé IA. À récupérer sur console.groq.com/keys. Elle est stockée uniquement sur ton téléphone (localStorage), puis utilisée uniquement pour appeler Groq.

⚠️ Comme l'appli appelle Groq directement depuis le navigateur, ta clé est visible dans le code du navigateur. Garde le lien de cette appli privé, ne le partage pas publiquement.
